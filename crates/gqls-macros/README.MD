![GQLite logo](https://gqlite.org/assets/images/logo-88x88.png) gqls-macros
===========================================================================

`gqls-macros` is part of the [GQLite project](https://gqlite.org) project, it provides macros for generating ORM-like API for GQL in Rust. This crate should not be used directly, instead, you should use the `gqls` crate, which contains the required runtime.
